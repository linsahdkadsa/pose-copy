# 踩过的坑（2026-10-15～10-22 测试）

## 合成感、比例
- **先出空场景、再把人放进去 → 一定像贴图**。Banana 只要拿到底板图就会原样保住每个像素，人永远是贴在上面的一层；写「只当地点参考」也没用（测试 6）。人和场景要一次生成。
- 白膜写成「store-display mannequin」→ 被画成橱窗模特：小头、腿特长、约 2 米高（样本4）。要写「matte white clay figure」并用场景物件定尺寸。
- 广角近拍会把腿拉长；写 50mm、腰高、3～4 米。

## 光、质感
- 人物资产的影棚光、磨皮会被带进成片 → 写「ONLY an identity reference」并列出不照搬的东西。
- 人比墙亮、白衣服比白墙白 → 一看就是单独打光；提示词里直接要求「人不比墙亮、白衣服和墙同色」。
- banana 每次出图偏洋红并累积 → 每步修色（白膜流程⑤）。
- 项目里的 临摹姿势/tools/harmonize.py 能把人物色温、亮度往场景拉，但改不了光的方向和皮肤质感，只能小修。

## 内容审核（被拦不扣费）
- 白膜写「光滑白色人体、没有衣服纹理」→ 被当成裸体拦；写成「穿白色紧身连体衣的人台」。
- 「把真人女性换成穿紧身衣的人台」这种改图常被 banana 拦，审核还时紧时松（10/20 晚上连拦 5 次）。→ 白膜放在去人底板上做、不带真人原图；还拦就换 image2.5。
- 看起来年轻的校服类参考图会被拦。
- 同一请求连拦 2 次就别硬试。

## 姿势
- 在原图上改姿势（原图 + 姿势照 + 文字）→ 原图自己的姿势会压过参考。一步法不给原图，姿势照才起作用。
- 只给骨架线不给白膜 → 交叉腿会错；白膜和骨架分两张给效果差，要画在同一张上。
- 在原图上直接换白膜 → 原图的腿姿（如交叉腿）会被保留。
- Vision 在白膜上经常整体左右反、缺手腕脚尖 → 标关节工具按 S / X 修。
- 露胳膊时骨架颜色会被画成手套 → 写「彩色线只是参考，手臂是皮肤」。
- 迁移时出现两个人（原图里的她 + 新姿势的她）→ 迁移要以叠骨架图为底写「把白膜换成她」，原图只当身份参考（10/21 #6971）。
- 拿一步法成片当原图做迁移，图 2 用原图 → 模型直接照搬原图姿势、骨架线留在身上（10/21 #6980）。图 2 换成人物资产（10/21 #6981）。
- 一步法写「Natural and relaxed, not a stiff studio pose」→ 时装摆拍姿势被放松走样；改成「holds this pose naturally, not stiff」。
- 站姿 3/4 侧转、顶胯：一步法写清角度也被拉回正面（#6973、#6974）；白膜那步 image2.5 能摆准（#6979）。

- 姿势写「head turns back toward the camera」，场景又写「看画面左边的盆栽」→ 头转反、视线看画面右（10/22 Codex G01）。改法：重抽时写鼻尖朝向 + 视线方向 + 「not toward the frame's right」（#7068）；或在成片上只改头（#7067）。

## 真实感
- 写「Only one person」→ 旺角深夜、便利店、雪街空无一人，像布景（#6987、#6990、#6991）。公共场所改成远处两三个虚化路人（#7008、#7006、#7010）。
- 不写相机直出 → 默认出电影调色、HDR 感、美颜光。
- 「framed off-center」基本不听，要偏构图就后期裁。

## 人物
- 客户实拍全身照当资产、脸很小 → 脸变成另一个人（10/21 #6983、#6986）。加一张脸部特写当第 3 张参考图后锁住（#6987）。
- 衣服细节在夜景里变哑光（亮片滚边）→ 提示词写出材质 glittering sequins。

## 文件和接口
- 用户在聊天里贴的图拿不到文件，要让用户拖文件进聊天框或放进文件夹。
- apimart：参考图文件名别带「+」，图床读不了。
- apimart：banana-pro 传 n:2 只出 1 张，要一张一张交。
- Codex 自带生图（10/22 实测）：没有比例、尺寸参数，3:4 靠提示词；出图只有 1086×1448；不返回扣费。两张参考图按顺序都能吃。
- 报错 / 超时 / 断连（broken pipe、SSL EOF、read timed out）：先看生图工具的账本和余额；没扣费再重交；扣了没出图要告诉用户。
- APIMart 不要并发提交。
- 报「图生成出来了但一张都没下载下来（钱已经花了）」：错误里带着图片地址，用 `curl -sfL --retry 3 <地址> -o 文件.jpg` 自己下回来，别重交（10/21 找回成功）。
