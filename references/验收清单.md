# 验收清单（每张出图都过一遍，放大看）

交图前自己先看；有一条没过就说清楚是哪条，别只说「效果不错」。
和参考图、人物资产并排看，不要只看缩略图。裁脸、手、脚各一块放大看：有 Pillow 就用它裁，有 ffmpeg 用 crop；macOS 上都没有时用自带的 `sips -c 高 宽 --cropOffset 上 左 原图 --out 局部.png`。

1. **姿势**：哪只手在画面哪边、在干什么，腿怎么放，头朝哪，身体转向哪边，和参考图一一对上。参考里被挡住看不见的部位不算错，交图时说明是推断的。
2. **没有镜像**：参考里画面左边那只手，成片里也在画面左边。小图上最容易看错，要放大。
3. **是同一个人**：脸型、五官、痣、发型和人物资产对得上（AI 资产痣位置会轻微漂，记一句即可）。姿势本身挡住了半张脸时，按露出来的部分 + 发型 + 身材判断，并在交图时说明「脸被挡，只能确认到这一步」。
4. **衣服和鞋**：和要求一致，细节（亮片、滚边、腰带）和长短（吊带到不到裤腰）也对；没有光脚（除非用户要，或在家里、床上、沙滩、野餐垫上）；没有多出来的衣服、手套、袖子（用户同意加的外套除外）。
5. **比例**：用场景里的物件对（桌面在胯、靠背到腰、门框比人高）；腿没有被广角拉长；人不过大也不过小。
6. **光感统一**：人和场景是同一种光、同一个色温；人不比背景里的白墙亮；白衣服和白墙同色；脸上有场景光该有的影子；脚下有接触阴影。
7. **质感统一**：人和背景的颗粒、清晰度一样；皮肤没有磨皮感。
8. **没有残留**：没有骨架线、彩色肢体、白膜痕迹；她身边没有多出来的人（公共场所远处虚化的路人可以）；手指和脚趾数正常。
9. **场景对**：是用户要的地方；招牌文字乱码不影响主体可以接受，主体附近的文字乱码要指出。
10. **像真照片**：场景有生活痕迹，不是样板间；公共场所远处有路人、她身边没人；没有青橙/赛博调色、没有 HDR 感；人身上的光不比场景干净。

不过怎么办：
- 1、2 不过 → 先对照参考查姿势段有没有写错（头的朝向最常写反），改对再重抽 1 次（先报价）；还不过 → 走白膜流程补救。只差身体侧转的，重抽一般没用，直接补救。
- 3 不过 → 资产是全身照、脸小的，加一张脸部特写当第 3 张参考图再重抽；其他情况把五官、痣写得更具体。
- 4 不过 → 提示词里把衣服的材质、长短写出来（glittering sequins、camisole reaching the waistband）再重抽。
- 5～7 不过 → 检查是不是漏了一步法里的光、镜头、「资产只用来认人」那几句。
- 10 不过 → 检查一步法模板里「真实感那几句」有没有写全。
- 8 不过 → 白膜流程里检查「彩色线只是参考」那句有没有写；骨架线留着、姿势又变回原图的，是图 2 用了同构图的原图，按白膜流程④换成人物资产。
